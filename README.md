# button
the best html button in the world


Steps : 

Create a palette procedurally using oklch and css vars 

Use light-dark() to select the correct color-space for the button background

Use contrast-color() for the button text

The button uses display:inline-grid with an icon column and a plain text column.
No inner label element is required: `<button class="button">Click Me</button>`.

the border-radius is a css-var as is the border size

there are strong visual indicators for :focus-visible, :focus-within, :hover and :active
